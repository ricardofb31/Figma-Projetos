# App Bar do ISTEC – Layout

Design completo do layout de uma aplicação móvel para consultar o menu do Bar do ISTEC (bolos, sandes, bebidas e refeições) e reservar os produtos com antecedência. Feito no Figma.

**Ficheiro Figma:** [Abrir](LINK_FIGMA)

## O que fiz
- Desenhei todo o layout da aplicação, de raiz.
- Criei o ecrã de explorar o menu, com pesquisa e categorias.
- Criei o ecrã de detalhe do produto, com a opção de reservar.
- Criei os ecrãs de reservas ativas e histórico.
- Criei o ecrã de perfil.
